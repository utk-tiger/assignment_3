Stack AI Rewire — Data Science

Assignment 3 — AI Native – Data Discovery

Overview
Run and critically verify an AI-assisted, multi-agent data-discovery workflow: locating, cataloguing, and assessing the feasibility of internal and external data sources for a business problem before any pipeline is built. You will steer a multi-agent pipeline (plan, scout, profile, assess, memo), parse metadata into structured records, encode deterministic feasibility rules and calibrated agent judgement, catch discovery-time traps, execute gate decisions and sign-offs, and package your learnings into a reusable skill file.

Use cases covered
Multi-Agent Pipeline Execution & Steering. Run and steer a multi-agent data discovery system (Plan, Scout, Profile, Risk Assessor, Memo Writer) while auditing agent execution traces and conversation transcripts.
Metadata Extraction & Format Parsing. Build deterministic tool extractors for licensing (schema.org JSON-LD, links, text) and complex domain formats (JSON-stat summaries).
Feasibility Rules & Risk Calibration. Encode deterministic feasibility rules (window coverage, staleness, grain mismatches) and calibrate LLM risk assessor rules against discovery traps.
Host Allowlisting & Agent Debugging (G7). Enforce strict host allowlists, identify root-cause agent failures in traces, and implement prompt, tool, or validator fixes with before/after evidence.
Human-in-the-Loop Gate Decisions & Sign-off. Manage candidate gate reviews, evaluate external source suggestions, review feasibility memos, and record formal sign-off decisions with traced evidence.
Skill File Extension & Reuse Verification. Extend the reusable data-discovery skill file for end-to-end execution and verify its performance on new, unseen use cases.
Expected outcome
A complete data discovery system with closed core gaps (G1–G7), execution artifacts and traces for two business use cases (UC1 & UC2), gate and sign-off decision logs, memo review reports, an extended reusable skill file, passing test suites, and submission evidence.
